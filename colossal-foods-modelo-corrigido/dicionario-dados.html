Dicionário de Dados Conceitual — Colossal Foods

Entrega 1 — Modelo Conceitual (DER)

Privacidade: este documento descreve somente a estrutura conceitual. Não contém dados pessoais reais de clientes, funcionários, motoboys ou fornecedores.

AtributoDescriçãoRegra de negócio associada

data_horaMomento do pagamentoObrigatório quando confirmado
